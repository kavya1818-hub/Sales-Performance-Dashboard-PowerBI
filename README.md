# Sales Performance Dashboard – Power BI

## Project Overview

This project is an interactive Sales Performance Dashboard built using Power BI to analyze business sales performance, profitability, regional trends, and customer insights.

The dashboard provides visual analytics for:
- Total Sales
- Total Profit
- Profit Margin
- Order Trends
- Regional Sales Distribution
- Category-wise Sales
- State-wise Sales Analysis
- Profit by State using Map Visualization

---

## Tools & Technologies Used

- Power BI
- DAX
- Data Visualization
- Microsoft Bing Maps
- Sample Superstore Dataset

---

## Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

### Visualizations
- Sales Trend Over Time
- Sales by Region
- Sales by Category
- State-wise Sales Analysis
- Profit by State (Map)

### Interactive Filters
- Region Filter
- Category Filter
- Order Date Filter
